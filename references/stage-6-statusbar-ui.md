# 阶段 6 · 状态栏前端

产物 type：`statusbar-ui`。机制、HTML 骨架、正则格式、提示词条目在 `references/frontend-conventions.md`——**进入本阶段先读它**。本阶段只补状态栏特有的东西。

## 进入条件

- **必须有 `axis-system.yaml`**：状态栏显示的每一根条，都得有轴、范围、阈值。没有轴就先走阶段 4，或退一步只做"信息卡"（时间 / 地点 / 在场者，无条无数值）——后者写清是降级形态。
- 有 `naming.axes` 时逐条核对：条的名称、方向（升好还是降好）、范围都从那里取，**不新造轴名**。
- 用户明说要"状态栏 / 每轮显示数值 / 血条蓝条 / 面板"才进；只说"美化"先问是开局还是状态栏。
- **先判规模**：≤6 个字段、只需一排数字 → 细条（`templates/statusbar.html` 起手）；需要分区（人物 / 装备 / 势力 / 事件）→ 分页 HUD（顶部 tab 切换面板，`tab-alert` 小红点提示新条目）。分区数由轴数与场景属性数决定，**不为凑 tab 造字段**。
- `project.web_research: true`：界面要显示真实单位（如体温 ℃、货币汇率、年代）先查口径，虚构单位不查。
- 没装酒馆助手 → 按 `references/frontend-conventions.md` 开场那段告知，不做静态版。

## 追问

**充分性评估**三项全满足则直接生成：① 显示哪几根轴（可从 `axis-system` 直接推）② 每根条的取值区间与方向（同上）③ 面板放哪（正文上方 / 正文下方 / 角落浮层）。

不满足则追问，**最多 2 轮、每轮 ≤3 问**，每题 2–3 选项 + 其他。可问的只有五类：

| 可问 | 例 |
|---|---|
| 跟随本楼还是跟随最新楼 | 本楼（每楼留快照）/ 最新楼（永远显示当前） |
| 变化要不要显示箭头 | 「灯芯 72 ↓8」，或只显示绝对值 |
| 阈值要不要上色 | 低于 30 变琥珀、低于 10 变朱红 |
| 面板形态 | 细长横条 / 两列小卡 / 折叠面板 |
| 配色与材质 | 「盐白底+暗黄发光 / 黑底+青磷光」 |

不问：字体、圆角、动画时长、图标——自主决定。

2 轮后仍缺 → 补全标 `【AI补全·可替换】`，不再问。

## 判断标准

- **一眼读出处境**：不点开、不悬停，就能看出哪根条快到底了。危险态必须在视觉上比正常态更抢眼（颜色或亮度，不是加粗字）。
- **不加解释**：条上不写"这是灯芯值，低于 20 会熄"这类说明书；量的语义由轴名本身承担。
- **不抢正文**：面板高度不超过一屏的 1/3，高度可收缩；不做固定悬浮遮罩。
- **数字与产物一致**：范围、方向、阈值分界全部来自 `axis-system.yaml`；界面里出现轴上没有的数字区间就是错的。
- **降级不崩**：某根轴本楼没给值 → 该条显示 `未知` 占位或整条隐去（按用户选择，默认整条隐去，不留空槽）。

## 生成

### 〇、先看有没有 `mvu`

契约 `stages.mvu: done` → **走 `references/frontend-conventions.md` 第二节的 D 路径**：状态栏不再要求模型输出 `<状态栏>` 块，直接读 `stat_data`，`findRegex` 用 `<StatusPlaceHolderImpl/>`、`maxDepth: 2`。此时"数据块"一节整节跳过。

没有 `mvu` → 按下面的一、二节走标签方案。两条不要混用：混用的结果是"有一条正则接不到任何东西"，看起来只是不显示，很难查。

### 一、数据块（AI 每轮输出什么）

每轮回复末尾输出一个 `<状态栏>` 块：

```
<状态栏>
<时间>潮历四十七年 · 第三次涨潮 · 夜</时间>
<地点>第七塔 · 塔顶灯室</地点>
<灯芯>72</灯芯>
<潮压>42</潮压>
</状态栏>
```

- 字段名 = 轴名或场景属性名，**逐字一致**；每个轴一行。
- 数值只写数字（`72`、`42`），不带单位和百分号；单位由界面按轴的 `range` 补。数值形态跟着轴的 `range` 走：`[0,100]` 写整数，`[0,1]` 才写小数——**不要凭轴名猜量级**。
- 不可知的值写 `未知`，不要写 `-`、`?`、`0`（`0` 会被当真值渲染）。
- 一屏内的补充信息最多 4 个非数值字段（时间、地点等）；再多就超出状态栏职责，砍掉。
- 标签 `<状态栏>` 与正则、HTML 的 `TAG` 三处一致。

### 二、HTML（`templates/statusbar.html` 起手）

- 字段表写在 JS 顶部 `FIELDS`，每项 `{name, min, max, kind: 'bar'|'text', dir: 'up'|'down'|'none', warn, danger}`；`min/max` 从轴 `range` 抄，`dir` 从轴 `direction` 抄（`descending` 的轴，值越低越危险）。
- 条：`<div class="rp-sb-bar"><span class="rp-sb-fill" style="width:72%"></span></div>`，宽度 = `(值-min)/(max-min)`，钳到 0–100。
- 危险：值进入 `danger` 区间加 `.is-danger`（换色 + 轻微呼吸动画，`prefers-reduced-motion` 时不动），进入 `warn` 加 `.is-warn`。
- 变化箭头：取上一楼同字段值比较，`↑/↓ + 差值`；取不到上一楼就不显示箭头，**不要显示 ↑0**。
- 本楼无标签 → `root.innerHTML=''` 留白，不显示"暂无数据"。
- `未知` 值 → 该条隐去（默认）或显示灰条 + `未知` 文字（用户选后者时）。
- 跟随最新楼模式下：`getChatMessages(-1)` + `eventOn(tavern_events.CHARACTER_MESSAGE_RENDERED, render)`，并在 `pagehide` 时 `eventClearAll()`（`references/frontend-conventions.md` 骨架里的 `render` 已含重渲染入口）。

### 三、正则（`regex-statusbar.json`）

`scriptName: "RP · 状态栏"`，`placement: [2]`，`markdownOnly: true`，`runOnEdit: true`，`substituteRegex: 0`。用户楼层也要看到同款面板时 `placement: [1, 2]`。

两种 `findRegex`，与数据路径配套（`references/frontend-conventions.md` 第二节）：

- **路径 B（默认）**：`/<状态栏>([\\s\\S]*?)<\\/状态栏>/g`，**带捕获组**；HTML 里保留 `<textarea id="rp-sb-raw" hidden>$1</textarea>`。数据与 HTML 在同一个正则脚本里，不依赖楼层 API，改消息也能重算。
- **路径 C**：`/<状态栏>[\\s\\S]*?<\\/状态栏>/g`，**不带捕获组**；HTML 里删掉那个 textarea。用于要做"跟随最新楼"或跨楼差值——这两种都需要读历史楼。

两种都写了就会互相抵销（B 有值时 C 永远拿不到历史），选一个。

### 四、提示词条目（`frontend-prompt.yaml`）

`内容` 段写：每轮末尾必输出该块、字段表、数值规则（只写数字 / 未知写"未知"）、不许解释。`插入位置` 建议"API 预设的越狱后置"，因为要覆盖每一轮；世界书用「常驻 + @D 深度 0」也可。

## 写回契约

- `stages.6` → `done` / `partial`（只出数据块与提示词）/ `skipped`。
- `artifacts` 追加：`statusbar-ui`（HTML）、`statusbar-ui-regex`（JSON）、`statusbar-ui-prompt`（YAML）。
- `naming.ui_tags.status` → `"状态栏"`。
- `hard_settings` 追加"状态栏每轮必输出"（`source: 用户确认`）——这条不进系统提示词就等于没做。
- `pending`：轴未定的（`[待定：轴名]`）、用户还没决定跟随本楼还是最新楼的，登记在此。
- `decisions` 记：跟随模式、危险阈值上色、降级形态（信息卡 / 无箭头 / 隐去未知）。

## 退出

- 前端门十条逐条过（`references/frontend-conventions.md` 第六节）；**阶段收尾一检** `python scripts/check-stage.py statusbar <项目根>`（内部跑 `validate-frontend.py` 查 `statusbar-ui.html`）。
- 三种误数据各试一次：**缺字段**（删掉一根轴）→ 该条隐去且不报错；**越界值**（把 72 写成 140）→ 条钳到满格、数字照原样显示（便于发现模型漂移，不帮它擦屁股）；**脏值**（`<b>x</b>`）→ 显示字面文本。
- 数值一致性：把 `FIELDS` 的 `min/max` 与 `axis-system.yaml` 的 `range` 逐项对照，不一致就改界面，不改产物。
- 交付时三句话：正则怎么导入、渲染开关在哪、提示词条目贴哪里；另加一句"轴上没有的字段不要往状态栏塞"。
- 用户只要粘贴版 → 三个代码块给全；文件模态下三份产物写进 `创作痕迹/产物/`。
