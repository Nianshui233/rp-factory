# 边界用例 · 阶段控制器·

按 `wick` 的阈值（67 / 34）取边界与边界前后各两点：

| wick | 命中分支 | 加载的条目 |
|---|---|---|
| 100 | 清醒 | `[阶段]守夜所·清醒` |
| 68 | 清醒 | 同上 |
| **67** | 清醒（`>= 67`） | 同上 |
| **66** | 磨损（`>= 34`） | `[阶段]守夜所·磨损` |
| 34 | 磨损 | 同上 |
| **33** | 空壳（`else`） | `[阶段]守夜所·空壳` |
| 0 | 空壳 | 同上 |

校验器对这一份的要求：边界数值单调（67 → 34 递减）、末档是 `else` 兜底（允许不写 `<= 0`）、三个被控条目都存在且 `disable: true`。
