## 阶段 0 · 开局四问（2026-11-20）

### 问了什么
- 工作区：当前目录 / 用户常用目录 / 只要粘贴不落文件（3 个选项）
- 要跑哪几个阶段（多选，1 世界观 / 2 角色卡 / 3 场景卡 / 4 数值系统）
- 是否启用 NSFW
- 是否需要联网（要查外部资料吗，与是否同人无关）

### 用户答了什么
- 工作区：`examples/dry-run-盐湖守夜人`（示例内自证用）
- 阶段：四个全勾
- NSFW：启用，但只到 R15
- 联网：否，原创到底，专名全自造（借盐湖工业废墟的气味，不借任何具体作品与真实地点）

### 我的建议与用户偏离点
- 建议先只做世界观 + 角色卡（避免一次摊太开），用户全选 —— 下游影响：四个产物都要互相读，阶段 3/4 必须自己回查阶段 1 的硬设定
- 建议 NSFW 默认关（保守），用户开且限 R15 —— 下游影响：`rating: R15`，角色卡可写 `nsfw` 块，内容边界层自检必执行
- 建议开联网（盐湖、灯塔、盐业工艺本可以查真实资料），用户选否 —— 下游影响：`project.web_research: false`，全程不检索、不建 `检索来源.md`，专名与工艺细节全部自造，真实性由用户自行把关

### 本轮落下什么
- `project.workspace` / `project.stages_requested: [1,2,3,4]` / `project.mode: engineering` / `project.web_research: false`
- `content_boundaries` 锁 `nsfw: true` / `rating: R15` / `hard_no` 两条（边界门完成）
- `创作痕迹/contract.yaml` 建骨架；`最终产物/` 空目录
- 名字未定：先叫 `未命名项目`，后来定名「白潮」并重命名目录、回写 `project.name` 与 `project.workspace`
