白潮 · 导入说明
================================================================

这个包里有几份文件，按下面的顺序导。**第 3 步要手动粘贴一段 HTML**，别跳过——
其余全是点按钮。

1. 世界书
   世界书面板 → 导入 → 「白潮 世界书.json」
   文件名就是书名。改文件名等于换书名，卡里认的是同一个名字。

2. 角色卡
   角色页 → 导入 → 「白潮（纯净）.json」
   导完看一眼卡片设置里的「世界书」是不是「白潮 世界书」，
   右边小地球变绿就是挂上了。没变绿就手动选一次。

3. 正则 + 界面（两步，第二小步是手动的）
   a) 设置 → 扩展 → 正则 → 导入 → 选「正则.json」
      问「全局 / 角色专属 / 预设」时选**全局**。选全局不用再点允许，也不会只在某张卡里生效。
   b) 记事本打开「白潮 开局前端.html」→ 全选复制 → 回正则列表点开「RP · 建卡向导」
      → 把「替换」里那段【尚未粘贴界面】的文字整个删掉 → 粘上 HTML → 保存。
      有状态栏就再来一次：「白潮 状态栏.html」→ 粘到「RP · 状态栏」的替换里。
      粘贴时从 `<!DOCTYPE html>` 开始整段复制到 `</html>`。
      只取中间的 `<div>` 不会被当成界面，会当成一段普通代码块。

4. 酒馆助手脚本（做了 MVU 或分档控制器才有这一步）
   设置 → 扩展 → 酒馆助手 → 脚本库 → 导入 → 「白潮 酒馆助手脚本.json」
   导入之后这个文件夹是**关着的**，点一下开关把它打开。
   不开的话一条脚本都不跑，变量永远是初值，而且**没有任何报错**。
   顺手确认「消息渲染」是开着的（设置 → 扩展 → 酒馆助手 → 消息渲染）。

5. 第一次进聊天
   发一条消息让它初始化（MVU 要在第一条消息里跑一遍），然后看状态栏有没有数字。

检查清单
   □ 卡片设置里世界书是绿的
   □ 正则导入成全局；点开那条正则，替换里是 HTML 不是提示文字
   □ 酒馆助手脚本文件夹是开着的
   □ 第一条消息里有界面，不是一行字
   □ 数值不是初值（发了消息之后）

出问题先看这里
   - 消息里只有一行字：正则没粘、正则被禁用、或「消息渲染」没开。
   - 界面空白且控制台干净：替换里的 HTML 不完整（漏了 `</html>` 或 `<body>`）。
   - 状态栏一直是初值：脚本文件夹没开，或者没发消息触发初始化。
   - 提示找不到某个名字：世界书没挂上，回第 1、2 步。
