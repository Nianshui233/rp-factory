## 零、一句话

好看不是词藻，是四个决定：**颜色有来源、字体有分工、版式有层次、动效有节制**。四件事都能写死，所以都能被检查；没做到时通常不是审美问题，是没做决定（于是用了默认值）。

## 一、推色法：从世界观推，不从"感觉"推

### 第一步：抓三个意象 + 一个光源

从世界书里找**反复出现的物象**（原文摘句，不是形容词）和一个**光源**：

| 世界 | 三意象 | 光源 |
|---|---|---|
| 盐湖守夜人 | 盐壳、灯油、铁栅 | 提灯（暖） |
| 赛博港城 | 雨水、霓虹招牌、义体陶瓷 | 全息广告牌（冷紫→青） |
| 民国宅邸 | 绒布、黄铜、檀香灰 | 台灯与烛（暖黄，低照度） |
| 校园日常 | 粉笔灰、篮球架、便利贴 | 午后斜阳（暖白） |

光源决定**强调色**，意象决定**色板**，环境决定**底色**。三步不许跳。

### 第二步：光源 → 强调色

| 光源 | 色相区间 | 可用值（三选一） | 气质 |
|---|---|---|---|
| 提灯 / 烛 / 油灯 | 30–45° | `#b8862b` `#c98f2e` `#a3701f` | 暖、旧、有限 |
| 炉火 / 血 / 警示灯 | 0–12° | `#a4332a` `#8f2b24` `#c0392b` | 危险、生理性 |
| 霓虹（粉紫） | 300–330° | `#e0559a` `#c2478a` `#ff5fa2` | 夜、人造、躁 |
| 霓虹（青蓝） | 185–200° | `#3fb8c4` `#2b8fa8` `#5ad1d6` | 冷、电子 |
| 晨光 / 医院灯 | 50–60° | `#e3c56a` `#d8c98f` | 洁净到发白 |
| 无光（深渊 / 停电） | — | 不用暖色，用`#7f8b99`灰蓝 | 冷、失温 |

**一个界面只有一个强调色。** 第二个亮色必须是它的同族（明度高 15%、饱和低 20%），否则就是两个主题在一张卡里打架。

### 第三步：意象 → 色板（明度三档，不是纯度三档）

取意象里**最饱和的那个颜色**当中间档，向下取暗、向上取亮——变化的是明度，不是饱和度：

```css
--c-ink:    #1c1a17;   /* 意象的最暗处：铁栅、字、线 */
--c-mid:    #6b6459;   /* 意象本体：盐壳的灰白、绒布的暗红 */
--c-paper:  #efe9dc;   /* 环境底：纸、雾、墙面 */
```

反例（常见错误）：`#ff4d4d` / `#4dff88` / `#4d4dff`——三个同纯度的原色，是全屏 RGB 打架，不是配色。

### 第四步：底永远是"最低饱和"

底色的饱和度不超过 12%，否则所有字都变"贴纸"。除非本来就是印刷风（那就让它有纸感：`#efe9dc`、`#f2ead8`），也不要纯白 `#fff` 或纯黑 `#000`——纯色会让描边和阴影失去参照。

### 第五步：每个色值都要能回答"来自哪句话"

写不出出处的颜色就是"随便挑的"，会在第三次改稿时被自己推翻。写在设计稿的色板行后面：

```
色板  灯油琥珀 #b8862b（强调，来自"灯芯只剩一指宽的油"）
      冷蓝灰 #3a4652（主，来自"铁栅上的霜"）
      盐壳白 #e8e3d8（底，来自"盐壳在夜里是灰白的"）
```

### 反俗套五条（每条都会让界面立刻变"AI 生成"）

1. **紫蓝渐变**（`#667eea → #764ba2`）：AI 味第一名，除非设定里真有霓虹紫，否则别用
2. **纯黑底 + 纯金强调**：是最省事的"高级感"，也是最没有世界的
3. **三个以上高饱和色**：超过两个，读者就不知道该看哪
4. **没有光源的"科技蓝"**：冷色如果没有来源（屏幕、全息、冷库），就只是模板
5. **整页 `rgba(255,255,255,.05)` 玻璃卡片**：荧光玻璃只在有强背景时成立，酒馆里背景就是聊天气泡

## 二、风格配方库

十种，每种给「适用世界 / 纹理与边框 / 字体 / 动效 / 禁忌」。**照搬会重复，正确用法是挑一个当骨架，再换成本世界的色板与意象。**

### 1. 铅字报纸（E-Ink / Editorial Grid）

- 适用：现实主义、悬疑、年代感；需要"信息像文字一样被读"
- 纹理与边框：双细线分隔（`border-top: 3px double`）、报头大字 + 小字刊期、首字下沉（`::first-letter`）
- 字体：标题宋体 Heavy，正文宋体，数字等宽
- 动效：新条目自下 6px 浮入 180ms
- 禁忌：圆角、渐变、发光——一旦加了就不是铅字

### 2. 冷硬终端（Terminal CLI）

- 适用：系统流、监控、AI 视角、黑客
- 纹理与边框：等宽字体、`#0d0f0e` 底、单色荧光（`#7ddc6a` 或 `#5ad1d6`）、扫描线（`repeating-linear-gradient` 2px）
- 字体：等宽栈，全大写标签
- 动效：光标闪烁 500ms；行逐行出现 240ms
- 禁忌：不只一种荧光色；不用圆角大于 2px

### 3. 霓虹赛博（Cyberpunk / HUD FUI）

- 适用：赛博、义体、夜城
- 纹理与边框：深底 + 双侧描边发光（`box-shadow: 0 0 12px`）、斜切角（`clip-path: polygon(...)`）、细网格底纹
- 字体：无衬线窄体，标签加 `letter-spacing: .18em`
- 动效：呼吸 3s；故障抖动（`transform: translateX`）只在"受击"时触发
- 禁忌：紫蓝渐变之外再加三种荧光；全屏 glitch

### 4. 暗黑血污（Modern Dark + Organic）

- 适用：恐怖、生存、堕落值类数值
- 纹理与边框：暗红→暗紫层叠渐变（`linear-gradient` 四段）、`backdrop-filter: blur(12px)`、低频"心跳"（`box-shadow` 呼吸 5s）
- 字体：衬线正文（有肉感）+ 无衬线标签
- 动效：血滴下落（`translateY` + `scaleX` 收窄）、心跳
- 禁忌：同时用三处以上动效；亮红配纯黑（会显得廉价）

### 5. 纸本版画（Neubrutalism）

- 适用：怪谈、民俗、童话、强插画感
- 纹理与边框：实心硬投影 `box-shadow: 2px 2px 0 var(--c-ash)` + `border: 1.5px solid`，圆角 0–2px
- 字体：标题可用楷/仿宋，正文宋体
- 动效：按下时 `translate(1px,1px)`，影子同步缩短（"压下去"）
- 禁忌：任何模糊阴影（模糊就不是版画）

### 6. 泛黄胶片（Vintage Analog）

- 适用：回忆、旧时代、档案
- 纹理与边框：噪点（一层 SVG feTurbulence 或 4×4 点阵 `background-image`）、轻微色偏（整块 `filter: sepia(.12)`）、边角暗（`inset box-shadow`）
- 字体：宋体 + 手写体标注
- 动效：几乎没有；最多"冲洗"式淡入 400ms
- 禁忌：高对比、荧光色、锐利描边

### 7. 极简单色（Minimalist Monochrome）

- 适用：冷淡、精英、极简世界
- 纹理与边框：只有两种灰 + 一个强调色；用留白和字号做层次，不靠框线
- 字体：无衬线，标题字重 300（细）反而更贵
- 动效：数值变化时数字滚动 240ms
- 禁忌：加装饰——它的全部力量来自"少"

### 8. 古风卷轴（Nature Distilled）

- 适用：仙侠、古代、武侠
- 纹理与边框：宣纸底（`#efe6d3`）、朱印（方形红块 + 反白字）、竖排装饰标签（`writing-mode: vertical-rl` 只用于小标签）
- 字体：标题楷/行楷，正文宋体
- 动效：墨迹淡开 600ms（`opacity` + `filter: blur` 取反），慢
- 禁忌：把正文也竖排（酒馆里读不了）

### 9. 仪表盘（Data-Dense）

- 适用：数值多的系统、多角色关系网
- 纹理与边框：网格 `gap: 8px`、每块一个标签 + 数值 + 细条、分隔线 1px
- 字体：无衬线 + 数字等宽（`font-variant-numeric: tabular-nums`）
- 动效：条形 `width` 过渡 350ms（这是唯一允许动 `width` 的地方，因为它是数据）
- 禁忌：超过两列（700px 宽度下两列已是极限）

### 10. 手绘涂鸦（Sketch Hand-Drawn）

- 适用：轻喜剧、日常、儿童视角
- 纹理与边框：每角不同圆角（`border-radius: 255px 15px 225px 15px/15px 225px 15px 255px`）、轻微 `rotate`（-0.6°~0.6°）
- 字体：圆体/手写
- 动效：hover 时轻轻歪一下
- 禁忌：全页都歪（歪是强调，不是基调）

## 三、字体：只写系统栈

酒馆 iframe 里加载外部字体会被网络、CSP、离线三件事打掉，而 `@font-face` 又要把字库塞进 800KB 的正则。所以**默认只用系统栈**，容器里写全 fallback：

```css
--font-title: "Source Han Serif SC", "Noto Serif CJK SC", "Songti SC", "SimSun", serif;
--font-body:  "Source Han Sans SC", "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif;
--font-kai:   "Kaiti SC", "KaiTi", "STKaiti", serif;
--font-round: "Yuanti SC", "YouYuan", "PingFang SC", sans-serif;
--font-mono:  ui-monospace, "SF Mono", Consolas, "Roboto Mono", monospace;
```

**分工三条**：标题用一个族、正文一个族、数字用等宽（`tabular-nums`）。三个族是上限；两个族 + 等宽数字通常就够。

正文 **13–16px**，行高 **1.6–1.9**（中文比西文需要更大行高）；标签 11–12px 必须加 `letter-spacing: .06em`，否则中文小字发糊。

只有一种情况可以引外部字体：设计稿明确写了"本包允许联网加载字体"，且 CSS 里同时给了本地上限回退（`font-family: "Ma Shan Zheng", var(--font-kai)`）。

## 四、版式原型（选一个当骨架，别混搭）

按聊天区宽度画：桌面约 700px，手机约 360px。

### A. 单列仪表盘

```text
┌─────────────────────────────┐
│ 第三夜 · 守夜所      灯油 62 │ ← 一行元信息，用 · 分隔
├─────────────────────────────┤
│ 守夜人 3/5  ████████░░       │ ← 标签 · 数值 · 条
│ 潮汐   涨   ██████░░░░       │
└─────────────────────────────┘
```

用于：状态栏、数值面板。优点是永远不会排版失败；缺点是没有性格，所以**必须靠色板与字体补性格**。

### B. 报头 + 分栏

```text
┌───────────────┬─────────────┐
│ 头版：守夜人失 │ 侧栏         │
│ 踪 · 正文两栏   │ 潮汐表 · 小字 │
└───────────────┴─────────────┘
```

用于：世界观播报、日报、事件回顾。桌面两栏，手机上退化成 A。

### C. 标签页

```text
[ 身份 ][ 关系 ][ 日志 ]      ← 三个以内，激活项用色块或下划线
├─────────────────────────────┤
```

用于：信息量超过一屏的状态栏。**页签里不许放会变的数值**（切页时看不见关键状态）。

### D. 卡片网格

```text
┌────────┐ ┌────────┐ ┌────────┐
│ NPC A  │ │ NPC B  │ │ NPC C  │
└────────┘ └────────┘ └────────┘
```

`grid-template-columns: repeat(auto-fit, minmax(150px, 1fr))`；手机自动变一列。

### E. 计量条组

```text
好感 ████████░░░░ 72   ← 条 + 数字 + 变化量 (+3)
```

用于：3–8 个数值。超过 8 个改用 A 的紧凑行距，不要堆两列条。

### F. 时间线

```text
○ 第一夜  守夜开始
│
● 第三夜  灯油耗尽      ← 当前节点用实心
```

用 `::before` 画轴，不要用 SVG。

### G. 卡牌 / 抽卡

```text
╔══════════╗
║  [插图位]  ║
║ 名称  ★★★ ║
║ 描述两行   ║
╚══════════╝
```

用于：道具、技能、角色卡。插图位做成固定 `aspect-ratio` 的空框，没有图时显示单色块 + 字，不要留白破洞。

### H. 控制中心

```text
[ 保存 ][ 重掷 ][ 剧情提示 ][ 设置 ]   ← 四个按钮以内，44px 高
```

用于：真能改东西的界面。按钮要写"会发生什么"，不要写"确认"。

## 五、动效：三条规则 + 一张时长表

**规则一：动效只表达两种事**——状态变化（数值、门槛、受击）与到来（新条目出现）。装饰性循环动效全页最多一处。
**规则二：只能动 `transform` / `opacity` / `filter` / `box-shadow`。** 动 `width`/`height`/`top` 会触发重排，在 iframe 里会抖；唯一例外是数据条（`width` 就是数据本身）。
**规则三：`prefers-reduced-motion: reduce` 必须整段关掉。**

| 用途 | 时长 | 缓动 |
|---|---|---|
| hover / 按下反馈 | 150–200ms | `cubic-bezier(.25,.46,.45,.94)` |
| 条目出现（stagger） | 250–350ms | `cubic-bezier(.34,1.56,.64,1)`（回弹）或 `.215,.61,.355,1`（稳） |
| 数值变化 | 240–350ms | `cubic-bezier(.25,.46,.45,.94)` |
| 氛围循环（呼吸/扫描） | 2.4–8s | `ease-in-out`，`infinite` |
| 首屏淡入 | 400–600ms | `cubic-bezier(.19,1,.22,1)` |

```css
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
```

## 六、层级与间距：三个数就能定

- **色阶三档**：主文字 / 次要 / 弱（同一色相改明度，不要用纯灰）
- **间距四档**：4 / 8 / 12 / 16（块内 4–8，块间 12–16，块外 16–24）
- **边界二选一**：`1px solid` 细线 **或** 硬投影 `2px 2px 0`——同一界面里只能选一种，混用会像拼贴

描边宽度不超过 3px；圆角不超过 8px（除非整体是"圆润可爱"那一类）。

## 七、AI 味清单（写完自己扫一遍）

1. 紫蓝渐变背景
2. 纯黑底 + 纯金强调
3. 居中大标题 + 副标题 + 两个按钮（落地页版式，塞进聊天气泡里）
4. emoji 当图标（🎭 ⚔️ 📜）
5. 所有元素圆角 16px + 同一种柔和阴影
6. 全是 `rgba(255,255,255,.05)` 玻璃卡片，叠在气泡上什么也看不见
7. 三个以上高饱和色
8. 没有光源解释的"科技蓝"
9. 满屏动效（每个块都在闪）
10. 中文正文 12px、行高 1.4（读三段就累）
11. 数值条用渐变填充（看不出进度）
12. 每个区块都有独立标题栏（标题比内容多）

## 八、可访问性下限（不是"锦上添花"，是能用的线）

- 正文对比度 ≥ 4.5:1，大字 ≥ 3:1（`#888` 配 `#1a1a1a` 是 3.5:1，只能当次要文字）
- 可点区域 ≥ 44×44px
- 焦点可见（`outline` 不许 `none` 了事）
- 不只靠颜色表意（数值条要带数字，危险态要带文字或图标形状）
- 200% 缩放不横向滚动

## 九、写代码前的五个问题（答不出就别写）

1. 这个界面**最先被看的一行**是什么？（没有的话，说明还没有层级）
2. 三意象与光源分别是哪个？（答不出 → 色板是假的）
3. 版式原型用的是 A–H 里的哪一个？（混搭两个 → 重排会散）
4. 唯一的那个动效在表达什么状态？（表达不了 → 删掉）
5. 手机上（360px）最先丢哪一块？（丢不掉 → 说明它比你以为的重要，回去改结构）
