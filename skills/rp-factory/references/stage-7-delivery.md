## 判断标准

- **分包不内嵌**：卡装骨架、书装细节、正则装界面、脚本装数值。内嵌的每一件都有一套静默授权规则（S-28 / S-29），分开的四件导入失败时当场报错。
- **世界书名三处一致**：书的**文件名** = 酒馆里的书名 = 卡里 `data.extensions.world`。不一致时卡导进去不会自动挂书，也不报错（S-29）。
- **界面不是文件**：`.html` 导不进酒馆，只是**粘贴素材**。`正则.json` 里是**围栏包着的待粘占位** `"```html
【尚未粘贴界面】…
```"`；围栏不能删（酒馆先跑正则再过 Showdown，只有代码块里的 `<script>` 活得下来），留空等于删行。
- **第一楼不是裸标签**：`first_mes` 里的标签要被 `正则.json` 里某条 `findRegex` 接住，接不住就换成普通开场白。
- **界面看 DOM，不看消息文本**：`first_mes` 存的就是六个字 `<建卡向导>`，替换发生在显示层。判据是那一楼有没有 iframe/控件、控制台有无报错：出来时 `TH-render` + iframe≈674px，出不来时 iframe=0 且**毫无报错**（S-28）。
- **名字与契约一致**：卡名 = `delivery.st_name` = 卡文件名（不含"（纯净）"）。
- **必给 `导入说明.txt`**：四个默认关着的开关全靠这张纸。

### 三、世界书装什么（`<世界名> 世界书.json`）

形状是 native：`{"entries": {"0": {...}, "1": {...}}}`，键是字符串序号，条目 42 个字段见 `templates/st-worldbook.json`。**不要写成 `entries` 数组**（那是卡内 v2 形状，导进世界书面板参数会全丢）。

**参数、关键词、位置怎么定看 `references/worldbook-tuning.md`**（三灯、套餐、关键词、位置、递归、十二条自查），这里只管"切哪几块"。

| 来源 | 条数 | `constant` | `order` | `position` | `key` |
|---|---|---|---|---|---|
| 世界规则 / 这栋楼的默契 / 变更边界 / 世界怎么运转 / AI即兴约束 | 3–6 条，各一条 | `true` | 100–94 | `0` | `[]` |
| 信息分层（防剧透） | 1 | `true` | 85 | `4` + `depth: 2` | `[]` |
| 数值与判定 | 1 | `true` | 84 | `4` + `depth: 2` | `[]` |
| 文本状态栏协议（仅标签路径） | 1 | `true` | 70 | `4` + `depth: 0` | `[]` |
| **每个角色**（`制作文件/产物/rolecard/*.yaml`） | 每人 1 条 | `false` | 80–78 | `0` | 本名 + `alias[]` + 关系指代 + 绰号（8–15 个） |
| **每个地点**（`制作文件/产物/scene/…` 或 scene-sheet） | 每地点 1 条 | `false` | 76–74 | `0` | 地点名 + 区域名 + 场景指代（8–15 个） |
| 势力 / 时间线 / 常识 / 名词 | 各 1 条 | `false` | 88–82 | `0` | `factions[].name` + `alias[]` |

规矩：

- **只切不写**：`content` 是原稿的一节**逐行照搬**，不是它的摘要。**用 `scripts/cut-worldbook.py` 切**，别手抄：

```bash
python scripts/cut-worldbook.py --plan 制作文件/项目记录/世界书切割.yaml \
    --draft-root 制作文件/产物 --merge-protocol "导入包/<世界名> 世界书.json" \
    --out "导入包/<世界名> 世界书.json"
```

  plan（形状见 `templates/worldbook-plan.yaml`）里只写**选择**：哪一节、叫什么、什么关键词、什么顺序、是不是常驻；切的动作交给脚本，所以不可能顺手压掉半句。
- **为什么不能压缩**：删掉的每一句原本都是模型做判断时唯一的依据。《常见误解或谣言》压成「有一些谣言」，模型就只剩一个空标签；每级 `behavioral_signs` 压成一句，阈值与慢热就都不存在了。参考实现 `我，非我`（22 条 / 42,945 字 / 单条均 1,952 / 最长 6,184）就是整节搬。
- **长度不设上限**：关键词条目只在命中时才进上下文，长条目的代价只在它被点名的那一轮。常驻条目合计参考 ≤8000 字（W09 只报数不判定）；原稿一节超过 6000 字才按子标题再切一刀。
- **整份文件当一条**：`rolecard.yaml` / `scene-sheet.yaml` / `axis-system.yaml` 这种一份一个实体的，plan 里写 `whole:`。人物条目含 `psychology` / `behavior` / `attitudes` / `speech` 全部字段，只把 `nsfw` 分档挪出去（单独一条或并入「数值与判定」，看谁更近）。
- **切过就不许改**：只三种情况动字——节标题提为条目名、给「未来才该知道」的包 `[秘密]`、按分档挪 `nsfw`。
- **`未决事项` 不进书**（它是对账，留在 `制作文件/`），写进 plan 的 `skip` 里；脚本会把没切走的内容抖出来，抖出来的每一条都要么补切、要么进 `skip`。
- **一个 key 只归一条**：同名出现在两条里就失去判别力（`W08` 会拦）。
- **协议条目不进切割**（`[initvar]` / `[mvu_update]` / `[阶段]` / `[ejs]` / `[statusbar]` 开头的那几条）：它们来自阶段 6 的模板，`--merge-protocol` 会自动带过去；命名必须带方括号前缀，否则会被当成设定条目查逐字性。
- **MVU 三件套必须随书**：`--merge-mvu 制作文件/产物/mvu`。留在 `制作文件/` 里等于没交（W25 拦）。
- `uid` == 键序号；`excludeRecursion: true`（关键词别在递归里反复展开）。

### 四、正则装什么（`正则.json`）

一个 **数组**，一条正则一个对象，字段见 `templates/regex-frontend.json`（单对象文件也能导）。

- 阶段 5 有 → 一条：`findRegex` 只匹配标签（`/<建卡向导>/g`）、`placement: [2]`、`markdownOnly: true`、`runOnEdit: true`。
- 有 MVU：隐藏更新块的提示词与显示规则均启用。有变量状态栏就保留挂载标签；无面板时可用空替换隐藏它（隐藏类正则的空替换合法，S-26）。
- 有状态栏：MVU 路径匹配 `<StatusPlaceHolderImpl/>`，替换成读取本楼 stat_data 的界面；文本路径匹配项目标签，按选定的数据路径配置捕获组。
- **带界面的两条 `replaceString` 交出去时是待粘占位**，不是 HTML 也不是空：

````text
```html
【尚未粘贴界面】把这段说明整段换掉：打开「<世界名> 开局前端.html」，全选复制，
粘在围栏里面（开头那行与结尾那行保留）。
```
````

围栏是 `replaceString` 的一部分，用户粘的时候不能删开头那行。

- 源文件在 `制作文件/产物/{wizard-ui,statusbar-ui}.html`，交付时复制成 `<世界名> 开局前端.html` / `<世界名> 状态栏.html` 放进 `导入包/`。
- 需要 HTML 实体时用 `\u0026` 拼（`'\u0026amp;'`）：酒馆会二次解码，写 `&amp;` 会让脚本语法错、界面塌成 2px。

### 五、脚本装什么（`<世界名> 酒馆助手脚本.json`，只有做了 `mvu` / `ejs` 才有）

形状照插件导出：**平铺的对象数组**；两条别包文件夹，实测包了 `Mvu` 不出现。

- 正文从 `mvu` 阶段的 `tavern-script-*.json` 原样搬，**不要手抄**（会漂移）。
- **导入目标是「角色脚本」不是「全局脚本」**：全局在插件设置里，换张卡照跑；角色脚本存进这张卡的 `data.extensions.tavern_helper`，跟着卡走（`tavern-helper.md` 第九节）。
- `enabled` 写什么都无所谓：导入时一律置 `false` 并换 `id`（TH-11），用户还要开「角色脚本」总开关、逐条打开。
- **不要同时内嵌进卡**：内嵌要进白名单才跑，与单独导入的那份同时启用会跑两遍、数值翻倍。

### 六、装配五步（即 `导入说明.txt` 骨架）

## 导入并实测（用户答「要」才做）

三个脚本：`detect-sillytavern.py` 开局静默跑（找安装与实例）；`st-import.py` 逐件导入并回读；`st-probe.js` 无头 Chrome 打开酒馆点开卡量高度。

```
python scripts/st-import.py --st auto --pkg "导入包"
node scripts/st-probe.js --st http://127.0.0.1:8000 --char "<卡名>"
```

`st-import.py --pkg <目录>` 按内容认件，逐件处理：卡（导入后回读比卡名 / `first_mes` / `extensions.world`）、世界书（**文件名即书名**，回读比条目数与常驻字数）、正则（**只校验，不动设置**），然后交代用户自己导正则、粘 html。

**为什么正则不能脚本代劳**：运行中的酒馆是**客户端**持有 `extension_settings`。脚本 `POST /api/settings/save` 写进去 2 条，磁盘上能查到；但页面一刷新、或客户端下一次自动保存，就用内存里的旧数组把文件盖回去了——实测写完再打开一次角色卡，磁盘又变回 0 条。所以这一件只能界面导（`扩展 → 正则 → 导入`，选数组文件会一次导完），或者等酒馆关掉再改 `settings.json`。**不要**对用户说"正则已经导好了"。

`st-probe.js` 打开酒馆、点开卡、读第一条消息的 `iframe` 高度与 iframe 内文字：≥60px 且有字 = 渲染成功；没有 iframe = 正则没生效（插件没装 / 消息渲染关了 / 没导）；只有 2px = 内联脚本语法错，多半 HTML 实体被解码（跑 `validate-frontend.py` 看 F04）。

**依赖**：`st-probe.js` 要 `npm i puppeteer-core`（只装驱动，不下载 Chromium）；没装就如实说"验不了渲染，文件与导入结果都在"，别假装测过。

## 退出

```

```

它内部先跑 `validate-contract.py` 再跑 `validate-st-package.py`（想看单条输出也可以单独跑这两个，但判定以这一条命令为准）。

脚本在**本 skill 包**的 `scripts/` 下，不在用户项目里；当前目录不是包根时用绝对路径。第一个参数给 `导入包/`（也接受单给某个文件）。退出码 0 才叫过。它查的事：

1. **三件都在、不多不少**：`<世界名>（纯净）.json`、`正则.json`、`<世界名> 世界书.json`。
2. 卡：`spec == "chara_card_v2"`、`spec_version == "2.0"`、`data` 十四必填字段齐全；**不许有 `character_book`（C19）**；`data.extensions.regex_scripts` 必须为空（C20）；`extensions.world` 非空（C21）。
3. 书：`entries` 是**对象**不是数组（W01）；每条 `uid` == 键、`content` 非空、`key` 是数组、`position` ∈ 0–7、`order` 是数字、`disable` 是布尔；非常驻且无 `key` = 失败；常驻合计 ≤8000（X02）。
4. 正则：数组（R01）；每条 `scriptName` 非空、`findRegex` 能被 JS 编译（有 node 就实测）、`placement` 数组、`markdownOnly: true`；用了 `$1` 却没捕获组 = 失败。
5. 交叉：`extensions.world` == 世界书文件名（去 `.json`）（X03）；做了 `mvu` 时独立脚本文件里有 MVU 加载器且正则里有隐藏更新块（X06）；`first_mes` 里的标签能被某条正则接住（X04）；三件的占位符 0 命中（X05）；带界面的替换要么是待粘占位、要么是完整 HTML（R07）。
6. 调优：绿灯关键词 <8、未 `excludeRecursion`、`position` 2·3·5·6、`key` 带逗号、`order` 全同、`selective: false` 给 WARN；常驻字数只打印不判定（`W09`）。
